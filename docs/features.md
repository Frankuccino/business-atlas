# Business Atlas — Features

Status: v1 scope confirmed 2026-10-24

## Confirmed for v1

- **Content schema and loader** — Markdown + frontmatter, zod-validated, build
  emits a typed manifest.
- **Browse** — domain pages, A–Z glossary, type and difficulty filters, tag
  search.
- **Entry pages** — structured fields, related panel, "what to learn next".
- **Map view** — domain-grouped layout with `related` edges drawn on top.
- **Global search** — instant, over titles, aliases, acronyms, and body text.
- **Daily session** — 1 new term, 1 new framework/principle, review set, 1 quote.
- **Spaced repetition** — fixed ladder, mastery tracking, append-only review log.
- **Playbooks** — searchable by situation, with considerations, numbers, traps.
- **Progress** — mastery per entry, streak, weak-spot list.
- **Auth** — refresh-cookie, httpOnly, server-side session (mirrors Atlas).
- **Import/export** progress as JSON.

## Seeded first

Five domains: Finance & Accounting, Unit Economics & Metrics, Marketing &
Growth, Strategy, Entrepreneurship & Capital.

First source: The Personal MBA.

25–30 dense, cross-linked entries. Not 1000 shallow ones.

## Deferred

- Decision journal — needs a review loop, which is a second habit
- Coverage heatmap — needs data volume
- Case of the week
- Domain gate quizzes
- Author and figure pages
- Reading tracker and per-book notes

## Non-goals

- No social or sharing features
- No public API
- No course marketplace
- No mobile native app
- No GitHub streak automation
